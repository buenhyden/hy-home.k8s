# Reference: Agent Model Routing and Configuration

## Overview

Baseline routing for task-characteristic model selection and configuration.

## Reference Type

Repository-static research baseline.

## Authority Boundary

Model policy and provider documentation own model availability and runtime
configuration. Static adapters do not prove selection or access.

## Scope

It assigns model routing, evaluation, fallback, and promotion research to
WERPC-006.

## Definitions / Facts

### Model-routing baseline

`docs/00.agent-governance/model-policy.md` is current model-policy evidence.
Provider model availability, reasoning support, cost, latency, and runtime
resolution are Unverified.

### Configuration baseline

Tracked provider adapters are configuration evidence only. Authentication and
effective configuration are Unverified.

## Sources

No current provider catalog was checked in WERPC-001. Existing provider URLs
are dated predecessor evidence and require recheck.

## Review and Freshness

WERPC-006 owns source-backed routing analysis. Refresh after provider catalog,
model policy, or adapter changes.

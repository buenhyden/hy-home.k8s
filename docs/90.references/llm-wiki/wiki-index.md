# Reference: LLM WIKI Generated Index

> Generated by `scripts/generate-llm-wiki-index.sh`. Do not edit by hand; update the generator or the canonical owner links, then regenerate.

## Overview

이 문서는 `hy-home.k8s`의 LLM WIKI deterministic generated Markdown index다. Agent와 사람이 정책, 절차, runtime roster, GitOps 상태, reference 자료의 canonical owner를 빠르게 찾도록 돕는다.

이 문서는 검색/탐색용 링크맵이다. 정책, 절차, 배포 승인, runtime 권한, secret handling, live cluster mutation 기준을 새로 정의하지 않는다.

## Purpose

- Provide one deterministic generated entrypoint for LLM-readable repository navigation.
- Link each major topic to the canonical owner instead of copying policy or procedure text.
- Make stale LLM Wiki output detectable through `bash scripts/generate-llm-wiki-index.sh --check`.

## Authority Boundary

- **Authoritative for**:
  - Generated LLM Wiki entrypoint links.
  - Canonical owner lookup by repository domain.
  - Refresh trigger for this generated Markdown index.
- **Not authoritative for**:
  - Requirements, architecture decisions, specifications, execution plans, task evidence, policies, runbooks, incidents, release gates, runtime permissions, model routing, secret handling, live cluster mutation, or deployment approval.

## Scope

- Covers repo-local Markdown entrypoints and canonical owner links.
- Covers docs, Agent governance, GitOps, scripts, examples, templates, and version references.
- Does not cover vector storage, embeddings, retrieval services, runtime caches, static wiki sites, package manifests, lockfiles, or copied policy/procedure content.

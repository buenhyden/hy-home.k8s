# W03 Closing Records Technical Specification (Spec)

## Overview

### Intent

This approved change contract is the records half of the W03 closing phase of the external v14.7 execution package (task file line 16: "closing H19/H20/H21/H31"). ## Behavior Contract

### Normal Behavior

Data modeling and storage:

One optional record on `common_forms` (six properties), 14 reworded strings, and appended tables in one Task. No ledger key, status or approval value is copied into the ledger, and no registry value is copied into a Task as a second owner: the Task facts name the record they rest on.

Interfaces and data structures:

`docs/99.templates/contracts/document-profile.schema.json`: the `common_forms` object gains the six optional properties and the conditional rules shared with `shared_contract` (by reference to one definition where the schema allows it). `scripts/document_contracts.py`: the typed reader accepts the optional record and keeps `forms` as it is. ### Failure and Edge Cases

- A closure row that names a deleted package Task must name its frozen `commit:path` as plain text and never as a link.
- If the SPEC-0161 Task has moved to the Task form of SPEC-0203, the appended tables follow its sections and no recorded cell moves.
- If an unverified fact is found in a record while preparing the evidence table, it is recorded as a fact with its record and the user is told; it is not promoted without the user's statement.

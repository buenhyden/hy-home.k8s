`Registry` declares five fields and none is `route_state`, so
`getattr(registry, "route_state", "terminal")` resolves to `"terminal"` on every
run. Ten branches in `scripts/validate-links-and-owners.py` test that value.

| `_reviewed_source_pinned_alias_edges` | `!= "transition"` | always true | dead body |
| `_reviewed_immutable_historical_alias_edges` | calls the row above and nothing else | unreachable result | dead |
| `_immutable_historical_redirects` | called only from the dead helper | no live caller | dead |

Two candidates were rejected.

`_document_taxonomy_transition_manifest` and
`scripts/document-taxonomy-migration.json` carry `"state": "transition"` in the
manifest body, which is data rather than the registry's route state. The
function is called unconditionally and its `move_targets` output is one of the
eight projections composed in `_historical_migration_proof`, so it is a current
redirect owner. Retained.

`_work054_wp004b_targets` is called unconditionally from
`_historical_migration_proof` as well as from the dead selector at the
`known_paths` site. Only the dead call is removed. Retained.

The alias family the user approved is the first six rows. The remaining six were
found by the same measurement during WP-001 and are retired on the same evidence
rather than left as a second residue.

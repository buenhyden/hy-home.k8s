| 90.references | data member | `DATA-####-m####` |
| 98.archive | migration | `MIG-####` |
| 98.archive | tombstone | `tomb-<TYPE>-####` |

A trailing group is the sequence inside the parent, not a repeat of the parent
number. Filenames of numbered leaf documents begin with their number, except
that a Stage 03 Task keeps `tsk-####-` and a Stage 90 pack member uses
`m####-`. Stage 00 governance documents and Stage 99 template files carry no
identity and keep their names.

### Point-in-Time Baseline

Read-only observation on 2026-09-01. These are audit counts, not invariants.

| Stage | Observation | Disposition |
| --- | --- | --- |
| 05.operations | 15 identities across guide, policy, and runbook; filenames already `####-` | Verify only; no incident or postmortem document exists yet |
| 98.archive migrations | 9 `MIG-####` identities | Identity verified; 3 filenames still carry a `mig-` prefix |
| 03.specs | 54 Plans as `PLAN-####`, 343 Tasks as `TSK-####-####` | Move both patterns and every presenting document |
| 90.references | one research pack with 13 members and no identity field | Introduce member identity and `m####-` filenames |
| 98.archive tombstones | 17 records identified by `sha256(legacy_path + NUL + source_blob)` | Replace the derivation; archived payloads carry no identity to prefix |

The tombstone digest is derived by `scripts/archive_recovery.py` as part of the
archive recovery proof, so this is a contract change rather than a rename.

## Approval and Safety Boundaries

- **Allowed Paths**: `docs/03.specs/**`, `docs/05.operations/**`,
  `docs/90.references/**`, `docs/98.archive/**` envelopes and derivation,
  `docs/99.templates/registry.json`, `docs/99.templates/contracts/**`,
  `docs/99.templates/templates/**` content, and the validators and tests that
  own these contracts.
- **Forbidden Paths**: Stage 00 governance document paths, Stage 99 template
  file paths, hook and provider configuration paths, sealed Stage 98 payload
  bytes, unrelated user changes, and live cluster or credential surfaces.
- **Additional Approval Required**: push, merge, pull request creation, any
  parent numbering change, and any change to a machine-loaded path.
- **Static Validation**: focused suites, affected and staged lanes, strict
  registry, Markdown, link, and lifecycle gates, archive recovery and
  validation suites, the repository aggregate, and diff checks.
- **Live Validation**: `DEFER` — this package changes repository documents and
  contracts only and proves no hosted, provider-runtime, or cluster behavior.
- **Secret / Vault Handling**: no secret or credential value is read or
  printed.
- **Rollback Plan**: per logical commit, one work package at a time; revert
  only the failed unit and never edit a sealed payload as rollback.
- **Evidence Location**: this Task for point-in-time execution evidence and
  reachable Git for rename and recovery history.

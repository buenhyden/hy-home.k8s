### WP-001 diagnosis

Six axes were run over 98 tracked files in `docs/00.agent-governance/`,
`.agents/`, `.claude/` and `.codex/`.

| Claim | Machine fact | Verdict |
| --- | --- | --- |
| The progress ledger states its own status consistently | Its header instructs new entries through the progress template while `memory/README.md` forbids appending new-work status, and its header names a removed `harness-catalog.md` as current runtime truth | correct |
| Commit-pin density is spread across the surfaces | 232 of 234 pins are in the ledger; `.agents`, `.claude` and `.codex` hold none | correct at one owner |
| Skills name only owned save locations | `ops-runbook/skill.md` offers `docs/05.operations/playbooks/`, which does not exist beside the owned `runbooks/` | correct |
| Every tracked artifact has a consumer | `.codex/rules/` holds one `.gitkeep` with no reference in the repository | correct by removal |
| Responsibility documents duplicate the registry roster | `roles/README.md` states the seven are a router and not a roster or permission inventory; the registry owns the twelve roles | reject |
| A Stage 00 contract is unconsumed | All nine contracts have consumers | reject |
| `post-validate-runner-result.py` is an orphan hook | `post-validate.sh` invokes it and three test modules cover it; the first sweep excluded the hooks directory | reject |
| `tests/verify-contracts-static.sh` is missing | The citation is `infrastructure/tests/verify-contracts-static.sh`, which exists; the path regex dropped the prefix | reject |
| Provider skill directories duplicate the shared owner | `.claude/skills` and `.codex/skills` are symlinks to `.agents/skills` | reject |
| Gateways duplicate policy | The four gateway files are 17 to 35 lines and carry routing only | reject |
| The ledger body cites removed paths | `memory/README.md` forbids rewriting the historical body to conceal stale paths | reject |
| Incident skills cite missing incident directories | `INC-###-<title>` is a placeholder pattern, not a path | reject |

Two sweeps were corrected before their results were used. A fixture and
artifact sweep matching basenames reported orphans that a full-path match
disproved. A constant sweep reading one module at a time reported dead names
that other modules import.

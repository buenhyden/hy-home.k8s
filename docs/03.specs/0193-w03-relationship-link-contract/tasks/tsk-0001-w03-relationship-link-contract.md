The staged guard shows exactly one MAJOR.

Interpretations the Spec leaves open, each applied so that the repository registry passes: the cycle rule pairs the i-th source profile of the structural-ownership relation `parent` with its i-th target (a literal edge from every source to every target would make Plan its own parent); the supersession walk draws each edge from the predecessor to its successor, so a reciprocal pair is one edge and not a loop; the relations `promotion` and `supersession` keep the names the Spec lists although the same sentence says no relation shares an ID with a kind, and the rule checks each set of IDs on its own; BODY-LINK-SOURCE and BODY-LINK-SOURCE-PROFILE are formed at run time from the link direction, so the entries cite BODY-LINK-BROKEN and name the others in their gaps. The registry and schema sections were spliced in by a scratch generator run from the shell, and the fragment slug rule reads ATX headings only, so a Setext heading offers no anchor.

Per-entry read, one line for each relation and link type (rule, what it enforces, gap):

- parent: PARENT-IDENTITY compares `parent_ids` with the one identity `direct_parent` derives from the package path, and TASK-PARENT-APPROVAL needs approved typed parents; gap: a Spec carries no parent_ids.
- requirement-basis: BODY-CONTRACT-IDENTIFIER requires complete requirement identifiers in the identifier columns, and BODY-LINK-BROKEN requires a tracked document of the allowed source profile; gap: the source and source profile rule IDs are formed at run time.
- design-constraint: BODY-LINK-BROKEN checks the Architecture-side columns that are link columns; gap: the Spec Architecture column is no link column, so its links are unchecked.
- promotion: PLAN-PROMOTION requires one Promotion table with a current owner or the sole none row; gap: the table is read by a script and not a body contract.
- supersession: LIFECYCLE-EVIDENCE refuses a chain without a current document and, from this package, a cycle; gap: an identifier naming no document is not refused.
- verification-evidence: TASK-EVIDENCE-COLUMNS, TASK-EVIDENCE-CRITERION and BODY-LINK-BROKEN check the columns, the criterion identifiers and the link; gap: no changed-file rule compares a criterion identifier with the parent Spec's criteria.
- policy-authority: REGISTRY_SCHEMA checks the shape of `policy_refs`, and LINK-BROKEN with LINK-STAGE-BOUNDARY the links; gap: no rule checks that a policy_refs path exists.
- consumer-impact: REGISTRY_KEY_CONSUMER and REGISTRY_KEY_TEST check the consumer paths and tests of a key; gap: a TemplateDefinition's consumer_paths are not checked for existence.
- normative link: BODY-LINK-BROKEN and LINK-STAGE-BOUNDARY; no gap recorded.
- evidence link: TASK-EVIDENCE-LOCATION requires a concrete check, input and location; gap: it does not check that the location resolves.
- historical link: no rule, the archive stays unchecked (ADR-0053); gap: reachability of a commit:path reference is a manual review.

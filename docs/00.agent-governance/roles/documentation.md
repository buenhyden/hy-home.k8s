# Documentation Responsibility

## Overview

Keep authored documents and navigation useful, traceable, and correctly routed.

## Authority Boundary

Documentation responsibility covers shared authoring/navigation concerns and assigned document edits, not authority over every stage's content. Stage owners retain substantive decisions; Stage 99 owns exact forms.

## Governance Context

Use Requirement, Architecture, Spec, Operations, Reference, and Archive owners according to purpose. Git history is the full-content archive; Stage 98 is a minimal recovery index.

## Current Contract

- Apply the selected profile/template and document language boundary.
- Keep current links and README navigation aligned with moves and deletions.
- Hand domain claims to their owner and research gaps to evidence collection; do not manufacture source support.
- Preserve completed or sealed evidence; use approved migration recovery instead of rewriting history.

## Validation and Refresh

Record evidence and handoff through [quality policy](../policies/quality.md).
Reassess responsibility when the active Task changes scope; exact role,
permission, skill, and handoff membership stays in the agent registry.
